# Datasets

Datasets used by the notebooks in this repository. They are public teaching datasets.

| File | Used in |
| --- | --- |
| `AR_DATA.csv` | Time series: smoothing and ARIMA |
| `Bulbs_Lifespan.csv`, `ecommerce_two_sample_ztest_dataset.csv` | Probability distributions and tests |
| `banking.csv` | Visualisation with Matplotlib |
| `daily-minimum-temperatures.xls` | Time series visualisation |
| `bangalore house price.csv` | Regularisation |
| `breast_cancer.csv` | Data partitioning, logistic regression |
| `breast-cancer-wisconsin-data.csv` | KNN, PCA |
| `Cars_4vars.csv`, `experience_vs_salary.csv` | Linear regression |
| `Diab.csv` | Data transformation |
| `first_file.csv`, `second_file.csv`, `third_file.csv`, `market.csv` | Data cleaning and statistics, PPS |
| `Market_Basket_Optimisation.csv`, `Movie.csv` | Association rules and recommendations |
| `Medical Cost Prediction.csv` | Artificial neural network |
| `mushroom.csv` | Naive Bayes, SVM assignment |
| `Non_linear_SVM_Dataset.csv` | Support vector machine |
| `nyc_weather.csv` | Functions and descriptive statistics |
| `sales.csv` | Decision tree |
| `shopping_data.csv` | Clustering |

The remaining files (`apple.txt`, `daily-minimum-temperatures.csv`, `diabetes.csv`, `glass.csv`, `heart_disease.csv`, `india-covid-19-…`, `nyc_weather_copy.csv`) are extra practice data.

## Data not included

Some assignments use datasets supplied by the course, which are not stored here: Titanic, Cardiotocographic, Adult income, Toyota Corolla, Zoo, East-West Airlines, Online Retail, Anime, Exchange Rate, Blogs and Alphabets.
